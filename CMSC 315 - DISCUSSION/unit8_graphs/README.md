# Unit 8 Discussion: Breadth-First Search (BFS)

## Overview

This assignment explores graph traversal using Breadth-First Search (BFS).

## Learning Objectives

- Represent graphs using adjacency lists
- Implement BFS
- Use queues in graph traversal
- Analyze graph traversal behavior

## Requirements

1. Create a graph.
2. Perform BFS traversal.
3. Add nodes or edges.
4. Demonstrate edge cases.
5. Analyze BFS behavior.
6. Create a real-world graph example.

3. Compare BFS and DFS conceptually and describe real-world applications and use cases.
While BFS and DFS both perform graph traversal, BFS spans out to all neighboring nodes as it progresses whilst DFS dives down a path as far as it can. Each one has their own use cases based on what they can achieve and their memory usage in action. BFS would be useful for a GPS system, as there are multiple paths that can be taken so it may need to fan out to find the shortest one more effectively. DFS can prove itself useful with garbage collection to mark reachable objects so others can be cleaned out, or implemented into things like procedural generation to create a randomized path.
