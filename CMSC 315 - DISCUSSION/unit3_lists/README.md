# Unit 3 Discussion: List Operations

## Overview

This assignment examines insertion, deletion, and searching in Python lists.

## Learning Objectives

- Insert values into a list
- Delete values from a list
- Search for values in a list
- Analyze list behavior and performance

## Requirements

1. Test insertion at the beginning, middle, and end.
2. Test deletion at the beginning, middle, and end.
3. Search for existing and missing values.
4. Demonstrate edge cases.
5. Create a real-world scenario.

3. How do list operations impact performance in real-world applications?

List operations are incredibly important for modifying and maintaining a list that may be in active use. However, in a similar vain to SQL, you need to be careful with how you utilize operations. Ensuring that your implementation uses the least amount of resources possible is key, but for this assignemnt some operations could use an extended amount of resources and subsequently impacting performance due to the potential of an operation's worst case scenario coming into play. When inserting an item for example, it shifts every item from the specified index and up forward one. That alone can have a major impact on performance depending on the size of the list you are working with.
